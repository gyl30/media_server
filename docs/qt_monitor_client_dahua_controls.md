# 大华云台与预置位实机验证补充

## 一、范围与结论

2026年10月16日，在独立测试平台上通过既有 HTTP 控制入口、GB28181 SIP 消息及摄像机只读状态接口，验证真实大华摄像机的云台点动、停止、预置位保存、调用、删除和原位恢复。摄像机型号为 DH-SD-P3A1205-P，设备编号为 `34020000001320000089`，通道编号为 `34020000001310000089`。

本阶段没有修改生产代码，没有新增生命周期状态、重试或厂商控制协议层。只读厂商接口用于独立观察设备状态与验证测试后的恢复，不替代平台的标准 GB28181 控制路径。本次不是实际 Qt 按钮的人工端到端验收，也不代表整个七阶段平台已经通过验收。

### 现有返回语义为何仍然是未确认

`signaling/gb_ptz.go:178–190` 将方向和变倍的START事务限定为300毫秒，退出后使用独立上下文尝试STOP；预置位事务则使用1500毫秒。`signaling/catalog.go:132–134` 将SIP事务错误原样返回。

当前锁定依赖为sipgo v1.6.0。其 `client.go:213–234` 的 `Do()` 在context结束后返回并终止事务；`sip/transaction_client_tx.go:223–249` 停止事务计时器，`sip/transaction_layer.go:372–375` 删除匹配项。稍后的200进入未匹配响应路径，不会使已结束的HTTP结果恢复成功。

因此，现有502 `ptz_start_failed` 在本次证据中表示“300毫秒内START事务未确认”，**不表示设备没有执行动作**。左右各一次、两次变倍的HTTP失败事实必须保留，不能用坐标变化覆盖或改写为接口全部PASS。

HTTP结果分别保存在上述TEST目录的 `06-left-64.json`、`09-right-32.json`、`12-zoom-in-4.json`、`15-zoom-out-4.json`；这些文件仅作为私有证据保留，不将原始响应或运行凭据提交到仓库。

不能简单将START事务改为1500毫秒并另外在300毫秒发送STOP：未终止的UDP事务可能在STOP之后重传START，改变已确定的安全语义。该版本的公开 ClientTransaction 接口没有“只停止请求重传、仍保留迟到响应匹配”的独立操作；通过全局未匹配响应处理器关联迟到响应会新增关联、期限及清理协调。此阶段没有为兼容迟到200引入这些机制，也没有修改全局SIP计时器或第三方依赖。

## 四、验收边界与后续事项

本次可独立确认：临时预置位3保存和删除、左右实际运动、动作后停止、调用原位恢复、最终三坐标及原列表恢复。现有点动事务成功窗口与该设备应答延迟存在真实兼容限制，变倍物理生效仍未证实。

以下不得写作已完成：Qt按钮人工实机验收、声学或人工画面对比、全部方向与其他云台功能、STOP中断goto、丢包故障下的物理停止保证、所有潜在自动动作均已禁用、整个平台或GB28181全标准符合性。

后续若要分离运动期限与事务确认期限，应先独立评审其响应关联、重传停止和生命周期成本；不能通过延长动作时间、自动重试或忽略HTTP502获得表面通过。本阶段结论仅为所列实机证据及兼容边界，不是整个平台GO。

待独立修正的可用性问题：`ptz_start_failed` 将未确认与明确拒绝混为一类，容易使操作员误判实际动作；应先保留错误身份与STOP合同，再评审准确的接口错误分类及Qt提示，不能把本报告视为该问题已修复。
