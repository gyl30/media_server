## 2. 场景与实际观察

执行前已保存判据。三份固定8秒循环素材均为640×360、25fps、H.264/AAC，分别有红/蓝/绿左上标记及440/880/1320Hz音调；实际文件SHA、生成命令、启动PID/starttime、授权和原始日志均留在私有证据目录。不是将三种图案当作三个物理设备。

使用同一逻辑push设备，A正常发布后自然结束，再使用新的发布凭据接入B；B播放中先停止本轮Go/media，实际FFmpeg因断开的连接退出，再用同一数据库、新服务PID恢复，旧媒体没有恢复，设备为used且media_ready=false。随后新凭据接入C，用户式刷新、双击和开声恢复。没有新增自动重连，也不把新的发布凭据SHA冒充网络上独立验证的新播放票据。

第二轮最终设备列表空、receiver列表空、所有自有PID与进程组均消失、27180–27184可重绑，私有X11认证文件已删除；Go/media均正常退出0。`parec`通过INT正常退出0、Pulse/Xvfb退出0，属于受控停止而非自然EOF。资源最终无遗留不等于整个优雅关闭过程通过；C发布者清理失败仍阻止本轮全PASS。
